## Uso

Esta pasta mantém uma coleção organizada dos arquivos; ela não ativa automaticamente os agentes no Codex.

Conforme o [README do projeto de origem](https://github.com/VoltAgent/awesome-codex-subagents/blob/9abe3279a0aa4ee518381af800ca1062398f5433/README.md#installation), copie os arquivos `.toml` desejados para `.codex/agents/` no projeto ou para `~/.codex/agents/` no perfil do usuário. Em seguida, atualize a sessão do Codex e solicite explicitamente a delegação aos agentes.

Os nomes dos arquivos seguem a grafia do projeto de origem: `performance-engineer`, `documentation-engineer`, `devops-engineer` e `microservices-architect`.
