# Regras modulares para AGENTS.md

Esta pasta reúne regras curtas, separadas por assunto, para compor as instruções de trabalho da IA em um projeto. Cada arquivo concentra as regras de um tema, e o AGENTS.md do projeto funciona como guia para localizar, ler e seguir os arquivos aplicáveis à tarefa.

## Como usar

- Organize as regras em arquivos focados, com nomes que indiquem seu assunto.
- No AGENTS.md do projeto, indique o caminho de cada arquivo e quando a IA deve consultá-lo.
- Oriente a IA a ler e seguir as regras aplicáveis antes de executar a atividade correspondente.
- Mantenha o conteúdo de cada regra no arquivo do seu assunto e atualize as referências do guia quando necessário.

Por exemplo, o AGENTS.md pode orientar a leitura das regras de commits e branches antes de criar uma branch ou preparar um commit, e das regras de pull requests antes de abrir ou atualizar um PR. Os caminhos usados no guia devem corresponder à localização dos arquivos no projeto consumidor.
